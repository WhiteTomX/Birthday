### Warning

**WARNING — 401 HTML described as "self-contained" but loads external `/style.css`** *(affects AUTH-05 resilience)*

The comment in `_middleware.js` claims the response is self-contained, but it uses `<link rel="stylesheet" href="/style.css">`. This works because `/style.css` is in the public exclusion list, but the comment is misleading. If `/style.css` were ever moved back behind auth, the 401 page would silently lose all styling.
