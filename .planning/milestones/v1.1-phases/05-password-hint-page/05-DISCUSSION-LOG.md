## The Riddle

| Option | Description | Selected |
|--------|-------------|----------|
| The password itself | Riddle answer IS the password | |
| A theme/word associated with the password | Answer is related, not exact | |
| Just the concept of Geburtstag | Riddle broadly hints at "Geburtstag" or birthday date | ✓ |

**Format selected:** Warm & explanatory (vs. short & punchy)

**User's choice:** The riddle hints that the password is the user's birthday (not the specific date). Invited guests who know whose birthday it is will figure out the date themselves.

**Notes:** Password is a date format like "5dezember" or "05.12". The riddle must NOT hint at the specific date — only at the concept of "birthday". Agent-drafted riddle was approved:
> *Ich komme einmal im Jahr.*
> *Man bäckt mir einen Kuchen, zündet Kerzen an und singt für mich.*
> *Wer eingeladen ist, kennt mein Datum —*
> *und kennt damit auch das Passwort.*
