# Milestone v1.0: RSVP Site

**Status:** ✅ SHIPPED 2026-05-10
**Phases:** 1–4
**Total Plans:** 7

## Overview

A password-protected save-the-date RSVP site built on Cloudflare's free tier. Phase 1 deployed Basic Auth protection via a Pages Functions middleware. Phase 2 built the German save-the-date page and RSVP form UI. Phase 3 wired submissions to a Cloudflare Worker and D1 database for unique record storage. Phase 4 applied a warm festive visual redesign and made "Save the Date" prominent as on-page content.

## Phases

### Phase 1: Infrastructure & Auth

**Goal**: The site is live on Cloudflare and inaccessible without the correct password
**Depends on**: Nothing (first phase)
**Plans**: 2 plans

Plans:
- [x] 01-01: Project scaffold — auth middleware, German placeholder page, .gitignore
- [x] 01-02: Cloudflare Pages setup — connect GitHub, set SITE_PASSWORD secret, verify live auth

**Details:**
- `functions/_middleware.js`: ES Modules `onRequest` middleware intercepts every request, decodes Base64 `Authorization` header, compares to `env.SITE_PASSWORD`, calls `context.next()` on success or returns `401 + WWW-Authenticate` on failure
- `wrangler.jsonc`: Pages config (`name: birthday`, `pages_build_output_dir: public`)
- Live at `birthday-4om.pages.dev`; secret set via `wrangler pages secret put` (dashboard unreliable)

### Phase 3: RSVP Backend

**Goal**: RSVP submissions reach a Cloudflare Worker, are stored as unique records in D1, and guests see a German confirmation
**Depends on**: Phase 2
**Plans**: 3 plans

Plans:
- [x] 03-01: D1 infrastructure — schema.sql, wrangler.jsonc D1 binding, database creation
- [x] 03-02: Worker endpoint — functions/api/rsvp.js with validation, D1 insert, JSON responses
- [x] 03-03: Frontend wiring — script.js fetch submission, success/error states, end-to-end verification

**Details:**
- `schema.sql`: `CREATE TABLE IF NOT EXISTS rsvps (id TEXT PRIMARY KEY, name TEXT NOT NULL, contact_method TEXT, attendees INTEGER NOT NULL, submitted_at TEXT NOT NULL)`
- D1 database `birthday-rsvps` (ID: `4e2e93ff-ea5b-4cc3-8c2f-d469c79c88f4`, region WEUR)
- `functions/api/rsvp.js`: `onRequestPost` — validates name + attendees ≥ 1, `crypto.randomUUID()` PK, parameterized INSERT, generic error response
- `public/script.js`: `fetch('/api/rsvp', POST)` → loading state → success (`Danke, {name}! Deine Anmeldung wurde gespeichert.`) or retry
- XSS prevention: `textContent` (not `innerHTML`) for guest name in success message

## Milestone Summary

**Decimal Phases:** None

**Key Decisions:**

- Basic Auth via Pages Functions middleware — keeps site invite-only without paid Cloudflare Access
- Plain HTML/CSS/JS — no build step, fastest possible deployment cycle
- `crypto.randomUUID()` PK — no UNIQUE constraint on name, every submission is a new record
- Warm festive palette (`#FDF4E8` cream, `#C0395A` rose, `#C9900A` gold) — Phase 4 replaces cool-grey system
- `textContent` (not `innerHTML`) for user-supplied data — XSS prevention pattern established
- D1 for storage — simple SQL, integrated with Cloudflare, no external database

**Issues Resolved:**

- `wrangler.jsonc` initially included unsupported `secrets.required` field for Pages — removed
- Pages project internal name (`birthday`) differs from auto-generated subdomain (`birthday-4om.pages.dev`)
- `wrangler pages secret put` required for both production and preview environments (dashboard unreliable)

**Issues Deferred:**

- WARNING-01: Stale Phase 2 TODO comment in production HTML (`action="#" method="get"`) — functionally inert, `event.preventDefault()` unconditional
- WARNING-02: No upper-bound on `attendees` in Worker (frontend enforces MAX=10, backend only checks ≥ 1) — low risk on private site
- RSVP-03 spec ambiguity: "including zero" vs stepper MIN=1

**Technical Debt Incurred:**

- No formal VERIFICATION.md files during execution (retroactively created at milestone close)
- Phase 2 SUMMARY.md not written during execution (retroactively created at milestone close)
- Phase 3 SUMMARYs used plain text format without YAML frontmatter (retroactively added)
