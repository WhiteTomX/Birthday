## v1.1 Requirements — Password Hint Page

### Access Control UX

- [x] **AUTH-03**: Guest who provides no credentials sees a festive HTML page with a German birthday riddle (not a blank screen or plain-text "Unauthorized")
  - *Outcome: public/index.html renders at `/` (200 OK) — riddle visible. JS redirect to `/rsvp/` is intentional.*
  - *Verified: 13/13 integration paths ✅, E2E flow ✅, browser-confirmed ✅*

- [x] **AUTH-04**: Guest who enters wrong credentials sees the same festive hint page after dismissing the browser's auth dialog
  - *Outcome: `unauthorizedResponse()` returns 401 with full riddle HTML body — confirmed by browser test*
  - *Verified: Integration checker WIRED ✅, E2E flow ✅*

- [x] **AUTH-05**: The hint page matches the main site's festive design (warm palette `#FDF4E8` / `#C0395A` / `#C9900A`, same font stack, same visual language)
  - *Outcome: `style.css` publicly excluded from auth; both hint page and 401 HTML link `<link rel="stylesheet" href="/style.css">`*
  - *Verified: Integration checker WIRED ✅, browser visual confirm ✅*

- [x] **AUTH-06**: The hint page displays a short German riddle that hints at the password (Geburtstag theme)
  - *Outcome: German riddle in `public/index.html` (lines 13–16) and `_middleware.js` 401 body (lines 55–58)*
  - *Verified: Integration checker WIRED ✅, 4 riddle lines confirmed ✅*

- [x] **AUTH-07**: The 401 response includes `Cache-Control: no-store` to prevent CDN caching of the hint page
  - *Outcome: `_middleware.js` line 70 sets `Cache-Control: no-store` on all 401 responses*
  - *Verified: Integration checker WIRED ✅, header confirmed in browser test ✅*
