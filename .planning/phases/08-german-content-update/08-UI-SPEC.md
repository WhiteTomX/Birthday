## Copywriting Contract

All copy is in German, informal register ("ihr/euch", no formal "Sie"). Voice is first-person plural ("Wir/uns") throughout — no personal names in HTML.

### Hint Page Riddle (`public/index.html`)

Existing 4-line poem. One new "zu zweit" line is added; all other lines are kept verbatim.

**Locked existing lines (do not alter):**

```
Ich komme einmal im Jahr.
Man bäckt einen Kuchen, zündet Kerzen an und singt.
Wer eingeladen ist, kennt mein Datum —
und kennt damit auch das Passwort.
```

**New line placement:** After "singt für mich." as a build-up before the password clue. This reads as the most natural cadence: the gift-giving verse names singular and then reveals the "zu zweit" context before the password clue closes the poem.

**Full updated riddle (executor canonical copy):**

```
Ich komme einmal im Jahr.
Man bäckt einen Kuchen, zündet Kerzen an und singt für.
Dieses Jahr feiern wir ihn zu zweit.
Wer das Datum kennt —
kennt damit auch das Passwort.
```

Source: D-01, D-02, D-03 from `08-CONTEXT.md`; line placement at Claude's discretion (D-02).

### 401 Inline Riddle (`functions/_middleware.js` — `unauthorizedResponse()`)

Must match the hint page riddle exactly. Use the same 5-line poem above in the inline HTML string. Surrounding heading ("Falsches Passwort") and reload instruction ("Seite neu laden, um es erneut zu versuchen.") are unchanged.

Source: D-03 from `08-CONTEXT.md`.

### Save-the-Date Body Text (`public/rsvp/index.html`)

Replace all `<p>` elements between `<h1>5. Dezember</h1>` and `<div class="divider">` with the following. The `<p class="eyebrow">Save the Date</p>` line above the `<h1>` is kept unchanged. The form section below the divider is kept unchanged.

**Replacement body (executor canonical copy):**

```html
<p>Moin</p>
<p>Wir werden 30. Aus irgendwelchen Gründen ist das etwas Großes — und wir feiern das zusammen. Mit euch.</p>
<p>Die Location steht noch nicht fest, aber der Plan ist: gutes Buffet, und danach richtig feiern. Wir halten euch auf dem Laufenden, sobald wir mehr wissen.</p>
<p>Wenn wir jemanden vergessen haben — einfach den Link weitergeben!</p>
<p class="deadline">Je früher ihr euch anmeldet, desto besser — dann können wir besser planen.</p>
```

Copy decisions applied:

- D-04: informal "ihr/euch", "Wir/uns" voice throughout
- D-05: date implicit via `<h1>5. Dezember</h1>` (unchanged); venue TBD stated; buffet + celebrating plan included; share-the-link sentiment included; soft RSVP ask included
- D-06: no personal names
- D-07: `.deadline` replaced with soft no-deadline ask using "Je früher, desto besser" phrasing
