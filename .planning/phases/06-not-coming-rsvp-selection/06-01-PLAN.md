| T-06-01 | Tampering | SQL insert in not-coming.js | mitigate | Use D1 `prepare().bind()` parameterized statement (never string concatenation) — guest name is bound, not interpolated |
| T-06-02 | Information Disclosure | catch block on D1 failure | mitigate | Return generic `error: 'Database error'` 500; never surface `err` details to the client (mirrors rsvp.js) |
| T-06-03 | Denial of Service | unauthenticated request flood | accept | Endpoint sits behind Basic Auth (functions/_middleware.js) and Cloudflare's free-tier edge protections; low-value private RSVP site, no rate-limiter required |
| T-06-04 | Spoofing / Elevation | direct access to /api/not-coming | mitigate | Auth enforced upstream by functions/_middleware.js for all non-public routes; no auth bypass added in this endpoint |
| T-06-05 | Tampering | attendees forced > 0 via payload | mitigate | attendees is hardcoded `0` in bind() — never read from request body, so a decline cannot masquerade as an attendance |
| T-06-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this plan; zero new dependencies (uses native Workers globals crypto/Response and existing env.DB binding) |
