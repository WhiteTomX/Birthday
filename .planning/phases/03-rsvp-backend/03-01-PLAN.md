    ```sql
      contact_method TEXT,

      submitted_at  TEXT    NOT NULL
    );
    ```

    Column notes (per D-08 to D-10):
    - `id` TEXT PRIMARY KEY — generated by `crypto.randomUUID()` in the Worker (D-09)
    - `name` TEXT NOT NULL — guest's name from the form
    - `contact_method` TEXT (no NOT NULL) — nullable because contact selection is optional (D-10)
    - `attendees` INTEGER NOT NULL — stepper value, always ≥ 1
    - `submitted_at` TEXT NOT NULL — ISO 8601 string, e.g. `new Date().toISOString()`

    Use `IF NOT EXISTS` so re-running the file is idempotent.

<task type="checkpoint:human-action" gate="blocking">
  <name>Task 3: Create D1 database, fill in database_id, apply schema</name>
  <read_first>
    - wrangler.jsonc (confirm REPLACE_WITH_DATABASE_ID placeholder is present before starting)
    - .planning/phases/03-rsvp-backend/03-RESEARCH.md (Section 2 and 3 for exact commands)
  </read_first>
  <what-to-do>
    Run the following commands in order in your terminal. Each command and what to do with its
    output is described step by step.

    **Step 1 — Create the D1 database (one-time, run from project root):**
    ```bash
    npx wrangler d1 create birthday-rsvps
    ```
    The output will include a block like:
    ```
    ✅ Successfully created DB 'birthday-rsvps' in region WEUR
    Created your new D1 database.

    [[d1_databases]]
    binding = "DB"
    database_name = "birthday-rsvps"
    database_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
    ```
    Copy the UUID value from `database_id = "..."`.

    **Step 2 — Replace the placeholder in wrangler.jsonc:**
    Open `wrangler.jsonc` and replace the string `REPLACE_WITH_DATABASE_ID` with the UUID
    you just copied (keep the surrounding double-quotes). It should look like:
    ```jsonc
    "database_id": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
    ```

    **Step 3 — Apply the schema locally (for local dev testing):**
    ```bash
    npx wrangler d1 execute birthday-rsvps --local --file=./schema.sql
    ```
    Expected output: `🌀 Mapping SQL input into an array of statements` and `✅ Executed ...`

    **Step 4 — Apply the schema to production (remote):**
    ```bash
    npx wrangler d1 execute birthday-rsvps --remote --file=./schema.sql
    ```
    Expected output: similar success message referencing remote execution.

    **Step 5 — Verify the local schema applied correctly:**
    ```bash
    npx wrangler d1 execute birthday-rsvps --local --command="SELECT name FROM sqlite_master WHERE type='table' AND name='rsvps'"
    ```
    Expected output should include a row with `name: rsvps`.

    If `wrangler` asks you to log in, run `npx wrangler login` first.
  </what-to-do>

    - `npx wrangler d1 execute birthday-rsvps --local --command="SELECT name FROM sqlite_master WHERE type='table' AND name='rsvps'"` returns a row with name `rsvps`
