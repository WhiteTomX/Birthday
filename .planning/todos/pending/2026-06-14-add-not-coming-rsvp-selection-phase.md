## Problem

The RSVP system currently only allows guests to confirm attendance. There is no way for a guest to indicate they will not be attending the birthday. Without this option, the host has no clear signal for non-attending guests — they either get no response or must infer absence from silence.

## Solution

Add a new phase to the current milestone that introduces a "not coming" selection in the RSVP flow. The guest should be able to explicitly choose they won't attend, which gets recorded in D1 and is reflected in the host's view.
